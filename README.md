# Курсовая работа: Приложение для поиска вакансий.

## Краткое описание: Программа, которая получает информацию о вакансиях с платформы hh.ru в России, сохраняет ее в файл и позволяет удобно работать с ней: добавлять, фильтровать, удалять.

## Установка:

### Убедитесь, что у вас установлен Python 3.6 или более поздняя версия.

## Использование:

    1. Скачайте файл данных и поместите его в папку data в корне проекта.


	2. Запустите основную программу: python src/main.py

## Структура проекта

#### data/ - расположение vacancies.json cюда сохраняются вакансии.
#### src/ - основной код проекта.
#### main.py - точка входа в приложение.
#### src/job_api_class.py - Созданы Классы для работы с API hh.ru
#### src/save_json.py - Класс для сохранения вакансий в JSON, TXT, CSV и работе с ними
#### src/vacancy.py - Класс для представления и обработки данных вакансии
#### src/vacancy_utils.py - Классы для фильтрации вакансий по разным параметрам
#### tests/ - тестовые файлы.

Содержит тесты для всех основных функций проекта.
